About This Project

Problem Statement

Counterfeit medicines are a serious global health issue. This project uses machine learning to help identify potentially fake medicines based on their characteristics.

Dataset

Trained on 50,000 medicine records with features like drug name, manufacturer, price, batch number, country, and dates. Labels: Genuine (1) or Counterfeit (0).

Features Used

FeatureWhy It Helps
Price RatioCounterfeits are often cheaper than average
Days Until ExpiryShort remaining shelf life is suspicious
Medicine AgeVery old medicines may indicate stock issues
Shelf LifeAbnormal total shelf life is a red flag
Batch LengthUnusual batch numbers can indicate fakes
Manufacturer FrequencyRare manufacturers are riskier
Country RiskSome countries have higher counterfeit rates
Price Per DoseUnusual cost per mg signals counterfeits

Tech Stack

  • Backend: Python, Flask
  • ML: scikit-learn (Logistic Regression, Decision Tree, Random Forest)
  • Database: SQLite
  • Frontend: HTML, CSS

Limitations

  • This is a statistical estimate, not a laboratory test
  • Accuracy depends on training data quality
  • Should not replace professional verification
  • Built for educational purposes only
